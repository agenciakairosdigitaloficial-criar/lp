DÚVIDAS FREQUENTES

Antes de começar.

Posso usar a API oficial do WhatsApp?

Sim. Você pode configurar a API Oficial manualmente ou usar a Coexistência em contas elegíveis para manter o mesmo número no CRM e no WhatsApp Business do celular. Modelos de mensagem e ligações seguem as condições da conta e do plano.

O KAIROS ajuda a recuperar vendas pendentes?

Sim. Com uma integração ou webhook compatível, você pode usar eventos como compra iniciada e pagamento pendente para organizar o funil e configurar lembretes.

Preciso programar para configurar automações?

Você pode montar chatbots e workflows no editor visual. Integrações sob medida via API ou webhook podem exigir configuração técnica.

O que conta como uma conexão?

Uma conexão é um canal vinculado ao CRM, como um número de WhatsApp ou uma conta de Instagram. Confira os limites e canais disponíveis no seu plano.

O agente de IA pode transferir o atendimento?

Sim. Você pode configurar critérios para a IA qualificar contatos, encaminhar a conversa a uma pessoa e manter o histórico para a equipe.
